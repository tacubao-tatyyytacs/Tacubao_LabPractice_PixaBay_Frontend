# Pixabay API Frontend

## What is this project?
This is a simple Pixabay API frontend that allows users to search photos or videos on anything like cats, dogs, and etc...

## How this project works
When a search is submitted, JavaScript uses the Pixabay API to fetch matching results and displays them on the page. A loading indicator appears while the request is being processed, and an error message is shown if the request fails or no results are found.
The project uses HTML for the structure, CSS for styling, and JavaScript for API requests and displaying the results. The Pixabay API key is stored separately in config.js and excluded from Git using .gitignore.
